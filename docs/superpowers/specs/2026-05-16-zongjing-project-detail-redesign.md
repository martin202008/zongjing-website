# 宗靖官网 - 项目详情页改版设计

**日期**: 2026-05-16
**状态**: 已确认

## 设计目标

突出项目卖点，促进招商。采用卡片式布局，以图片为主视觉。

## 页面结构

### 1. Hero 区域
- **全屏主图**: 项目主图，60vh 高度
- **叠加信息**:
  - 项目名称（大字）
  - 核心标签（业态类型 badge）
  - 基础信息条：城市、地址、商业面积、开业状态

### 2. 核心卖点卡片（3卡片）

**卡片A: 区位优势**
- 配图：区位示意图（mmx 生成地图风格）
- 内容：地理位置描述、周边配套、交通优势

**卡片B: 客群分析**
- 配图：客群分析图（mmx 生成）
- 内容：目标客群特征（半径3公里社区居民）、消费能力、覆盖范围

**卡片C: 业态组合**
- 配图：业态规划图（mmx 生成）
- 内容：业态规划、楼层分布、品牌布局

### 3. 项目详情卡片
- **文字简介**: 现有 description
- **项目特色**: features 标签
- **配套设施**: floors, parking, position

### 4. 图集展示
- 现有 images 数组轮播展示

### 5. CTA 卡片
- 渐变背景
- 招商咨询引导
- 电话按钮: 0512-66188818
