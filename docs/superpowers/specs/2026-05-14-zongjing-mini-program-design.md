# 宗靖招赢小程序设计方案

**日期：** 2026/05/14
**状态：** 已确认

---

## 1. 背景与目标

宗靖官网现有招赢系统（PC 后台）已完整运行，包括招商工作台、线索管理、入驻申请管理等功能。现需要拓展至微信小程序，满足以下场景：

- 工作人员通过微信分享小程序给品牌方/商户
- 品牌方/商户通过小程序浏览项目、提交入驻申请
- 招商工作人员拥有个人电子名片，可分享给品牌方

**技术路线：** 原生微信小程序（方案三），复用现有后端 API

---

## 2. 产品架构

### 2.1 双端定位

| 端 | 定位 | 用户 |
|----|------|------|
| PC 管理后台 | 招商工作台 + 新增员工管理 | 招商工作人员 |
| 微信小程序 | 品牌方申请入口 + 员工电子名片 | 品牌方/商户 + 工作人员 |

### 2.2 小程序用户流程

```
工作人员 ──分享名片链接──→ 品牌方 ──查看名片──→ 拨打电话 / 提交申请
                                    ↓
                              浏览项目列表
                                    ↓
                              提交入驻申请
                                    ↓
                              PC 后台处理申请
```

## 3. PC 后台新增：员工名片管理

### 3.1 员工字段

| 字段 | 类型 | 说明 |
|------|------|------|
| 姓名 | 字符串（必填） | 员工真实姓名 |
| 职务 | 字符串 | 如：招商总监 |
| 部门 | 字符串 | 如：苏州相城分公司 |
| 手机号 | 字符串（必填） | 用于展示和登录 |
| 微信号 | 字符串 | 展示在名片上 |
| 头像 | 图片 | 上传员工照片 |
| 个人简介 | 字符串（选填） | 公司的简短介绍 |
| 状态 | 枚举 | 启用 / 禁用 |

### 3.2 管理功能

- 新增 / 编辑 / 删除员工
- 启用 / 禁用名片
- 查看每位员工名片的访问次数（可选）

### 3.3 新增后端接口

| 接口 | 方法 | 用途 |
|------|------|------|
| `/api/employees` | GET | 获取员工列表（后台管理） |
| `/api/employees` | POST | 新增员工 |
| `/api/employees/:id` | PUT | 编辑员工信息 |
| `/api/employees/:id` | DELETE | 删除员工 |
| `/api/employees/:id/card` | GET | 获取员工名片数据（小程序用） |

## 4. 微信小程序功能

### 4.1 页面列表

| 页面 | 路径 | 说明 |
|------|------|------|
| 首页 | `/pages/index/index` | 项目列表入口 + 员工名片入口 |
| 项目列表 | `/pages/projects/list` | 展示所有招商项目 |
| 项目详情 | `/pages/projects/detail?id=xxx` | 项目信息 + 申请入口 |
| 入驻申请 | `/pages/apply/apply?projectId=xxx` | 申请表单 |
| 我的申请 | `/pages/my-apply/list` | 手机号查询申请记录 |
| 电子名片 | `/pages/card/card?employeeId=xxx` | 员工名片（无需登录） |

### 4.2 名片页内容

- 员工头像
- 姓名
- 职务 + 部门
- 手机号（点击拨打 `wx.makePhoneCall`）
- 微信号（点击复制 `wx.setClipboardData`）
- 公司简介（宗靖商管介绍）
- 底部按钮：「申请入驻」「分享名片」

### 4.3 分享机制

- 每个员工有唯一的名片页面路径：`/pages/card/card?employeeId=xxx`
- 小程序右上角「...」→「发送给朋友」即可分享
- 品牌方收到分享后，无需登录直接查看名片
- 名片页内可直接跳转入驻申请

### 4.4 项目列表 / 详情 / 申请

复用现有 PC 端的移动版展示：

- 项目列表：卡片式，展示名称、位置、面积、类型
- 项目详情：Banner 图 + 项目简介 + 业态构成 + 申请入口
- 入驻申请：表单字段同现有 `/system/apply`
