# 宗靖官网设计规范

## 1. 项目概述

**项目名称**：宗靖官网
**项目目标**：品牌展示 + 业务导流（招赢系统注册 + 公司/项目了解）
**目标访客**：品牌方（商家）+ 商业地产运营商
**设计风格**：活力清新风（蓝绿渐变 + 柔和圆角 + 流动元素）

## 3. 视觉规范

### 3.1 配色方案

| 用途 | 色值 | 说明 |
|------|------|------|
| 主色 | `#1a56db` | 深蓝，品牌主色 |
| 辅色 | `#0ea5e9` | 天蓝，渐变过渡 |
| 点缀色 | `#06b6d4` | 青色，活力感 |
| 背景 | `#f0fdfa` | 淡青白，清新底色 |
| 文字主色 | `#1e293b` | 深灰蓝，主文字 |
| 文字辅色 | `#64748b` | 中灰，副文字 |

### 3.2 渐变方案

- **Banner 渐变**: `linear-gradient(135deg, #1a56db 0%, #0ea5e9 50%, #06b6d4 100%)`
- **按钮渐变**: `linear-gradient(135deg, #1a56db 0%, #0ea5e9 100%)`
- **装饰元素**: 圆角圆形，透明度 5-10%，营造流动感

### 3.3 字体规范

- **标题**: 思源黑体 / Noto Sans SC（Bold/Medium）
- **正文**: 思源黑体 / Noto Sans SC（Regular）
- **英文/数字**: Inter / system-ui

### 3.4 圆角与间距

- 卡片圆角: `12px`
- 按钮圆角: `8px`
- 大区块间距: `80px - 120px`
- 内容区最大宽度: `1200px`

## 4. 首页结构

### 4.1 首屏 Banner

- 全屏高度（约 100vh 或 600-700px）
- 品牌 Logo + 标语居中
- 渐变背景 + 流动装饰圆圈
- 底部导航栏固定悬浮

### 4.2 使命愿景区块

- 简短有力的使命语句（1-2 句话）
- 配以简洁的图标或插画
- 避免大段落文字

### 4.3 招赢系统介绍

- 系统核心价值 / 三大卖点
- 系统界面截图或功能图标展示
- CTA: "立即体验" 或 "了解更多"

### 4.4 运营项目展示

- 卡片式展示正在运营的商业项目
- 每个项目: 封面图 + 项目名 + 位置 + 简介
- "查看全部项目" 链接

### 4.5 底部 CTA + Footer

- 明确行动召唤: 注册招赢系统
- Footer: 导航链接 + 联系方式 + 版权信息

## 5. 技术方案

### 5.1 技术选型

- **框架**: Next.js 16 (App Router)
- **样式**: Tailwind CSS
- **UI 组件**: 可复用组件，活力清新风格
- **图标**: Lucide React / Heroicons
- **部署**: 与招赢系统共用服务器的 nginx 转发

## 6. 设计原则

1. **产品主导**: 系统功能展示优先，使命愿景作为品牌背书
2. **双目标并重**: 引导注册 + 项目了解同等重要
3. **活力清新**: 蓝绿渐变 + 流动装饰 + 柔和圆角
4. **信息扁平**: 减少文字量，用视觉元素传达信息
5. **转化清晰**: 每个区块都有明确的行动引导
6. **移动适配**: 响应式设计，适配手机/平板

## 8. 招赢系统核心卖点

- **精准匹配** — 基于大数据分析的智能推荐系统，为商户匹配合适的商铺资源
- **高效对接** — 实时沟通，快速响应入驻需求，降低沟通成本
- **安全可靠** — 严格的资质审核与合同保障，交易更放心

系统 slogan：**精准匹配 · 高效入驻**
