# 宗靖官网 Redesign 设计规范

**版本:** v1.0
**日期:** 2026-05-16
**风格:** 活力商业风

---

## 1. 概述

宗靖官网全新设计，采用活力商业风，以品牌蓝 `#1E40AF` 为主色，活力橙 `#F97316` 点缀，营造专业、年轻、充满活力的商业氛围。

---

## 2. 色彩体系

| 角色 | 色值 | 用途 |
|------|------|------|
| Primary | `#1E40AF` | 品牌蓝、按钮、导航、主要强调 |
| Secondary | `#F97316` | 活力橙、图标高亮、点缀 |
| Background Light | `#FFFFFF` | 主背景 |
| Background Alt | `#F8FAFC` | 区块背景 |
| Text Primary | `#0F172A` | 标题、大字 |
| Text Secondary | `#475569` | 正文 |
| Text Muted | `#64748B` | 辅助文字 |
| Border | `#E2E8F0` | 边框、分隔线 |

---

## 3. 页面结构

### 3.1 导航栏 (Header)

- 固定顶部，白色 80% 透明度 + backdrop-blur
- 左侧：Logo + "宗靖商管" 品牌名
- 右侧：招赢系统按钮（Primary色）
- 移动端：汉堡菜单

### 3.2 Hero 区域

- 全屏高度 90vh，轮播 3 张幻灯
- 幻灯内容：商业价值、城市发展、专业团队
- 背景：每张幻灯配对应图片，黑色 40-50% 遮罩
- 内容：大标题 + 副标题 + 三大统计数据（7+项目/100+品牌/50万㎡）
- 双 CTA 按钮："了解更多" + "立即入驻"
- 轮播控制：左右箭头 + 底部指示器（显示图标+文字）

### 3.3 关于我们

- 左图右文布局（比例 4:3）
- 左侧：团队照片 + 浮动"10+年行业经验"统计卡
- 右侧：标题 + 描述文字 + 三列特性（专业团队/数字平台/全流程）+ 了解更多链接

### 3.4 核心优势

- 背景：`#F8FAFC`
- 标题居中，三列卡片布局
- 三项：精准匹配、高效对接、安全可靠
- 卡片：白色背景 + hover 上浮 + 阴影增强

### 3.5 项目展示

- 白色背景
- 顶部：左侧标题，右侧"查看更多"按钮
- 3 列网格（响应式 1-3 列）
- 卡片内容：图片 + 业态标签 + 项目名 + 城市/面积
- 图片高度 48，hover scale 105%

### 3.6 CTA 区域

- 背景：渐变 `#1E40AF` → `#1E3A8A`
- 居中内容：标题 + 副标题 + 单按钮"立即入驻"
- 按钮链接：`http://124.222.144.78/system`

### 3.7 页脚

- 白色背景，上边框
- 居中：Logo + 公司名 + 版权信息

---

## 4. 字体与间距

- 标题：bold ~ extrabold
- 正文字号：14-16px
- 间距：8px 基准网格（8/16/24/32/48/64）

---

## 5. 动画

- 卡片 hover：translateY(-4px) + shadow-xl，duration 300-500ms
- 图片 hover：scale(1.05)，duration 500-700ms
- 轮播淡入淡出：opacity transition 1000ms
- 按钮 hover：opacity 90%，-translate-y-0.5

---

## 6. 技术实现

- 框架：Next.js (App Router)
- 样式：Tailwind CSS
- 图标：Lucide React
- 图片：Next/Image
- 无需额外 UI 库
